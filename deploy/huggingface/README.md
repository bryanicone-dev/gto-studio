# GTO Studio

Solver pós-flop de poker (Discounted CFR, via [postflop-solver](https://github.com/b-inary/postflop-solver)) compilado para WebAssembly: o cálculo roda no navegador de quem usa. Visualizador 13×13, filtros por categoria, ranges, gráfico de equity e trainer.

Este Space é gerado a partir do projeto `gto-studio` pelo script `deploy/huggingface/publish.ps1`. Edite o projeto, não este repositório.
